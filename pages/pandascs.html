Pandas Cheat Sheet

Referensi cepat untuk operasi data manipulation, cleaning, analysis, dan visualization menggunakan Python Pandas.

pandas v2.0+

📥 Import & Setup

Konvensi standar import library

import pandas as pd import numpy as np

📂 Load Data

Membaca dataset dari berbagai sumber

df = pd.read_csv('data.csv') df = pd.read_excel('data.xlsx', sheet_name='Sheet1') df = pd.read_sql('SELECT * FROM table', conn) df = pd.read_json('data.json') df = pd.read_parquet('data.parquet')

🔍 Inspect Data

Melihat struktur & statistik dataset

df.head(5) # Baris awal df.tail(3) # Baris akhir df.info() # Tipe data & null count df.describe() # Statistik numerik df.shape # (rows, cols) df.dtypes # Tipe data per kolom df.columns # Nama kolom df.nunique() # Jumlah nilai unik

✂️ Select & Filter

Memilih kolom, baris, & kondisi

df['col'] # Pilih 1 kolom (Series) df[['a', 'b']] # Pilih beberapa kolom df.iloc[0:5] # Berdasarkan posisi (row) df.loc[0:5, 'col'] # Berdasarkan label/index df[df['age'] > 25] # Filter condition df[df['city'].isin(['JKT', 'BDG'])]

🧹 Data Cleaning

Menangani missing value, duplikat, tipe data

df.dropna() # Hapus baris null df.fillna(0) # Isi null dengan 0 df['col'].fillna(method='ffill') # Forward fill df.drop_duplicates(subset=['id']) # Hapus duplikat df.rename(columns={'old': 'new'}) df['col'] = df['col'].astype(int)

⚙️ Transform & Compute

Manipulasi kolom & operasi vektor

df['total'] = df['qty'] * df['price'] df['status'] = df['score'].apply(lambda x: 'Lulus' if x >= 70 else 'Gagal') df['name'] = df['name'].str.lower.strip() df['birth'] = pd.to_datetime(df['birth']) df['age'] = pd.Timestamp.now().year - df['birth'].dt.year

📊 GroupBy & Aggregation

Analisis data per kategori

df.groupby('city')['sales'].sum() df.groupby(['dept', 'city']).agg({'salary': ['mean', 'max', 'count']}) df.pivot_table(index='month', columns='product', values='sales', aggfunc='sum') df.crosstab(df['gender'], df['purchased'])

🔗 Merge & Join

Menggabungkan DataFrame

pd.concat([df1, df2], axis=0) # Stack vertikal pd.concat([df1, df2], axis=1) # Stack horizontal pd.merge(df1, df2, on='id', how='inner') # default: inner pd.merge(df1, df2, left_on='a', right_on='b', how='left') df1.join(df2, how='outer', lsuffix='_l', rsuffix='_r')

📈 Sort & Rank

Mengurutkan & memberi peringkat

df.sort_values('sales', ascending=False) df.sort_values(['dept', 'salary'], ascending=[True, False]) df['rank'] = df['score'].rank(method='dense', ascending=False) df.nlargest(5, 'salary') df.nsmallest(3, 'age')

💾 Export Data

Menyimpan hasil olahan

df.to_csv('output.csv', index=False) df.to_excel('output.xlsx', sheet_name='Data') df.to_sql('table_name', conn, if_exists='replace') df.to_json('output.json', orient='records') df.to_parquet('output.parquet')

📉 Visualization

Plotting cepat dengan matplotlib/seaborn backend

df['col'].plot(kind='line') df.plot(x='date', y='sales', kind='bar') df.plot(kind='scatter', x='age', y='income', alpha=0.5) df.plot(kind='hist', bins=30, figsize=(8,5)) df.boxplot(column='salary', by='gender') df.plot.kde() # Density plot

🕰️ Time Series

Operasi data temporal & resampling

df['date'] = pd.to_datetime(df['date']) df = df.set_index('date') df.resample('M').mean() # Bulanan df.resample('D').sum() # Harian df['prev'] = df['value'].shift(1) df['roll_mean'] = df['value'].rolling(window=7).mean() df.between_time('09:00', '17:00')
