SQL Cheat Sheet

Panduan lengkap Structured Query Language: DDL, DML, JOIN, Subquery, hingga optimasi performa query.

MySQL / PostgreSQL

🏗️ Data Definition (DDL)

CREATE, ALTER, DROP & TRUNCATE tabel

CREATE TABLE pelanggan ( id INT PRIMARY KEY, nama VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE, dibuat DATE DEFAULT CURRENT_DATE ); ALTER TABLE pelanggan ADD COLUMN telepon VARCHAR(20); DROP TABLE IF EXISTS pelanggan; TRUNCATE TABLE pelanggan; # Kosongkan data
⚠️ DROP menghapus tabel permanen & tidak bisa di-rollback!

📦 Tipe Data & Constraints

Jenis data umum & aturan validasi kolom

Data Types:
  • INT / BIGINT - Bilangan bulat
  • DECIMAL(p,s) - Presisi tetap (uang)
  • VARCHAR(n) - Teks variabel
  • TEXT - Teks panjang
  • DATE / DATETIME - Tanggal & waktu
  • BOOLEAN - True / False
Constraints:
  • PRIMARY KEY - Unik & tidak null
  • FOREIGN KEY - Relasi antar tabel
  • UNIQUE - Nilai harus unik
  • CHECK - Validasi kondisi

➕🔄💾 Data Manipulation (DML)

INSERT, UPDATE, & DELETE data

-- Insert 1 baris INSERT INTO pelanggan (nama, email) VALUES ('Budi', 'budi@mail.com'); -- Update (SELALU gunakan WHERE!) UPDATE pelanggan SET umur = 30 WHERE id = 1; -- Delete DELETE FROM pelanggan WHERE id = 5;
💡 UPDATE/DELETE tanpa WHERE akan mengubah/menghapus SEMUA baris!

🔍 SELECT & Filtering

Mengambil, memfilter, & mengurutkan data

SELECT nama AS 'Nama', email FROM pelanggan WHERE umur > 20 AND kota IN ('JKT', 'BDG') OR email LIKE '%@gmail.com' ORDER BY nama ASC LIMIT 10 OFFSET 20; # Pagination

📊 Agregasi & GROUP BY

Fungsi ringkasan & pengelompokan data

SELECT kota, COUNT(*) AS total, AVG(gaji) AS rata_rata FROM karyawan GROUP BY kota HAVING COUNT(*) > 5 ORDER BY total DESC; # HAVING = WHERE untuk GROUP BY

🧮 String & Date Functions

Manipulasi teks & operasi temporal

UPPER(nama) # BUDI LOWER(email) # budi@mail.com CONCAT(nama, ' - ', kota) SUBSTRING(nama, 1, 3) # 3 huruf pertama LENGTH(nama) TRIM(nama) NOW() # Timestamp sekarang DATEDIFF(NOW(), tgl_lahir) SELECT * FROM log WHERE created_at >= '2024-01-01';

🔗 JOIN Operations

INNER, LEFT, RIGHT, SELF & Multi-table JOIN

-- INNER JOIN (cocok di kedua tabel) SELECT p.nama, o.total FROM pelanggan p INNER JOIN pesanan o ON p.id = o.id_pelanggan; -- LEFT JOIN (semua kiri + NULL kanan) LEFT JOIN pesanan o ON p.id = o.id_pelanggan WHERE o.id IS NULL; # Hanya yang belum pesan -- Multi Table JOIN item_pesanan i ON o.id = i.id_pesanan JOIN produk pr ON i.id_produk = pr.id;

🪆 Subquery & CASE

Query bersarang, EXISTS, & logika kondisional

-- Subquery di WHERE SELECT nama FROM produk WHERE harga > (SELECT AVG(harga) FROM produk); -- EXISTS (lebih cepat dari IN) WHERE EXISTS (SELECT 1 FROM pesanan WHERE id = p.id); -- CASE WHEN (If-Else SQL) SELECT nama, CASE WHEN skor >= 80 THEN 'A' WHEN skor >= 70 THEN 'B' ELSE 'C' END AS grade FROM nilai;

⚙️ Urutan Eksekusi & Performa

Bagaimana database memproses query & tips optimasi

🔄 Urutan Eksekusi Engine:
1. FROM 2. WHERE 3. GROUP BY 4. HAVING 5. SELECT 6. ORDER BY 7. LIMIT
✅ Gunakan INDEX pada kolom filter/JOIN
✅ Hindari SELECT *, ambil kolom spesifik
✅ Pakai EXPLAIN SELECT... untuk cek plan
❌ Hindari fungsi di WHERE (misal: YEAR(tgl)), pakai range

🔐 Transaction, DCL & View

Atomic operations, hak akses, & tabel virtual

-- Transaction (All or Nothing) START TRANSACTION; UPDATE akun SET saldo = saldo - 1000 WHERE id = 1; UPDATE akun SET saldo = saldo + 1000 WHERE id = 2; COMMIT; # atau ROLLBACK; jika error -- View (Tabel Virtual) CREATE VIEW v_detail AS SELECT p.nama, o.total FROM pesanan o JOIN pelanggan p ON o.id_p = p.id; GRANT SELECT ON db.* TO 'user'@'%';
