🗺️ Learning Roadmap

Roadmap Beginner → Advanced

Ikuti roadmap terstruktur untuk menguasai skill data dari nol hingga expert.

🟢 BEGINNER

Fundamentals

Pelajari dasar-dasar matematika, statistik, dan berpikir analitis.

Matematika Dasar Statistik Deskriptif Logika Analitis Excel / Google Sheets
🔵 ELEMENTARY

SQL & Database

Kuasai SQL untuk query, manipulasi, dan analisis data dari database.

MySQL / PostgreSQL SQL Queries (SELECT, JOIN) Window Functions Database Design
🟡 INTERMEDIATE

Python & Visualization

Gunakan Python untuk analisis data dan buat visualisasi yang impactful.

Python (Pandas, NumPy) Matplotlib & Seaborn Tableau / Power BI Exploratory Data Analysis
🟠 ADVANCED

Business Intelligence

Bangun dashboard, laporan otomatis, dan presentasi insight untuk stakeholder.

Dashboard Design KPI & Metrics Storytelling with Data A/B Testing
🔴 EXPERT

Advanced Analytics & Portfolio

Statistical modeling, predictive analytics, dan bangun portfolio profesional.

Regression & Classification Time Series Analysis Portfolio Projects Git & Collaboration
🟢 BEGINNER

Python & Matematika

Dasar Python, aljabar linear, kalkulus, dan probabilitas.

Python Basics Aljabar Linear Kalkulus Probabilitas
🔵 ELEMENTARY

Data Wrangling & EDA

Pandas, NumPy, visualisasi, dan exploratory data analysis mendalam.

Pandas Advanced NumPy Seaborn & Plotly Feature Engineering
🟡 INTERMEDIATE

Machine Learning

Supervised, unsupervised learning, model evaluation, dan tuning.

Scikit-learn Cross Validation Hyperparameter Tuning Ensemble Methods
🟠 ADVANCED

Deep Learning & AI

Neural networks, CNN, RNN, NLP, dan computer vision.

TensorFlow / PyTorch NLP (Transformers) Computer Vision Generative AI
🔴 EXPERT

MLOps & Production

Deploy model, monitoring, CI/CD untuk ML, dan sistem production-ready.

MLflow & Weights & Biases Docker & Kubernetes API Development (FastAPI) Model Monitoring
🟢 BEGINNER

Programming & Linux

Python, Linux command line, dan dasar-dasar sistem komputer.

Python Intermediate Linux & Bash Git & GitHub Networking Basics
🔵 ELEMENTARY

SQL & Data Warehousing

Advanced SQL, data modeling, dan konsep data warehouse.

Advanced SQL Star/Snowflake Schema BigQuery / Redshift dbt (data build tool)
🟡 INTERMEDIATE

ETL & Data Pipeline

Bangun pipeline data dengan Airflow, Spark, dan tools modern.

Apache Airflow Apache Spark Kafka / Streaming Data Quality
🟠 ADVANCED

Cloud & Infrastructure

Cloud platforms, IaC, containerization, dan orchestration.

AWS / GCP / Azure Docker & Kubernetes Terraform CI/CD Pipelines
🔴 EXPERT

Data Architecture & Optimization

Design data platform, optimization, governance, dan real-time systems.

Data Lakehouse Stream Processing Data Governance Performance Tuning
